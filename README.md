# Day of the Dogs 🐕

A delightful, animated celebration of our furry friends! This project features a fully animated scene with playful dogs, floating bones, drifting clouds, and more.

## Features

- 🐕 **Animated Dogs**: Two adorable dogs that walk back and forth with wagging tails and wiggling ears
- 🦴 **Floating Bones**: Three bones that float and rotate in the sky
- ☁️ **Moving Clouds**: Three clouds that drift across the sky at different speeds
- ☀️ **Animated Sun**: A glowing sun that rotates with pulsing shadow effects
- 🐾 **Paw Prints**: Fading paw prints that appear and disappear
- 📱 **Responsive Design**: Mobile-friendly layout that adapts to different screen sizes
- ✨ **Pure CSS Animations**: No JavaScript required - all animations use CSS keyframes

## How to View

Simply open `index.html` in any modern web browser. No build process or dependencies required!

Alternatively, you can serve it with a local server:
```bash
python3 -m http.server 8000
```
Then visit `http://localhost:8000/index.html`

## Technical Details

- **13 different CSS keyframe animations** for smooth, coordinated movement
- **Zero JavaScript** - lightweight and performant
- **Accessible** with proper overflow handling and flexible sizing
- **Semantic HTML** for better structure and maintainability

## Browser Compatibility

Works on all modern browsers that support CSS3 animations:
- Chrome/Edge (latest)
- Firefox (latest)
- Safari (latest)
- Mobile browsers
